Overview – Client Script & UI Policy

Client Script and UI Policy are used to control the Incident form behavior in ServiceNow.

Client Script: Uses JavaScript to make the form dynamic.
UI Policy: Controls field visibility, mandatory, and read-only based on conditions.

Example: When Incident State is Resolved, make Resolution Notes mandatory.
